# GenForge product identity

## Why

The repository is GenForge, but the application, installers, source folder and icons still use the previous identity. Selecting a provider also replaces the product branding with the model vendor.

## Changes

- Use GenForge for application identity, installer names, documentation and the source folder.
- Use one original G lettermark for application, browser and installer icons.
- Keep the selected model visible as secondary information while retaining the GenForge brand.
- Reuse existing local profiles and storage identifiers to preserve settings and conversations.

## Scope

No API model identifiers, generation behavior, application ID, author, license or release version changes. No dependency installation or release publishing.

## Tooling

The OpenSpec CLI is unavailable in this workspace. These spec-driven artifacts are maintained directly.
