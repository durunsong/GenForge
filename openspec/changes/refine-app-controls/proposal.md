# Refine application controls

## Why

Native dropdown popups, layered cards, gradients and oversized rounded controls make the application inconsistent and visually noisy across its tools.

## Changes

- Enhance every select with one accessible, theme-aware popover implementation.
- Preserve native select values, change events, option groups and dynamic models.
- Flatten tool navigation, forms, action buttons, tabs and tool surfaces.
- Verify drawing settings, provider CRUD and each tool on desktop and mobile.

No API contracts, storage keys, dependency versions or release behavior change. The OpenSpec CLI is unavailable; artifacts are maintained directly.
